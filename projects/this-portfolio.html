Overview

Design & approach.

The goal was a portfolio that loads instantly, looks great on any screen, and requires zero build steps — no webpack, no npm, no framework. Just a single HTML file deployable to GitHub Pages with a git push.

The design takes inspiration from editorial layouts: bold serif headings (Merriweather), clean Figtree body text, and a focused purple accent color that pulls attention to the right places.

Animations are driven by IntersectionObserver — elements fade and slide in as they enter the viewport. No libraries, no jank.

The Experience section uses a tab system written in vanilla JS. The nav highlights the active section as you scroll using a separate IntersectionObserver with a rootMargin offset.

Features

What's inside.

Single File

Everything — HTML, CSS, JS — in one file. No build process, no dependencies. Open in a browser and it just works.

Scroll Animations

Elements reveal on scroll using IntersectionObserver. Staggered delays create a layered, polished feel.

Fully Responsive

Mobile-first layout with a hamburger menu on small screens. Tested from 320px to 4K.

Project Detail Pages

Each project links to a dedicated detail page with an overview, features, and tech stack — consistent design system throughout.

Active Nav on Scroll

The navbar highlights the current section as you scroll, using a second IntersectionObserver with a center rootMargin.

GitHub Pages Ready

Push to the repo and it's live. No CI config, no server, no build step — just static files and a git push.
