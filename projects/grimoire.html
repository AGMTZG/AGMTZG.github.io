Overview

What is Grimoire?

Grimoire is a Shopify Online Store 2.0 theme (v1.0.0, by AGMTZG). It started from the official Shopify Skeleton, but the current product is a complete storefront with its own identity: a dark editorial aesthetic inspired by ritual, arcane language, and curated materiality.

It targets lifestyle, fashion, curated objects, and storytelling-heavy brands. Not an app, not Hydrogen — it's a classic Shopify theme that runs on the Online Store channel via Liquid + JSON templates + the visual theme editor.

Default palette: #0d0d0d background, #dddbd7 text, #111111 surfaces. Typography is fully configurable via Shopify's font_picker, exposed as CSS custom properties through snippets/css-variables.liquid.

UI patterns throughout the theme: uppercase eyebrows, hairline borders, luminous-border buttons, and smooth transitions (--timing: 0.3s token). Optional transparent header, fullscreen slideshow, product carousels, and a suite of drawers for menu, search, and cart.

The architecture follows Shopify's standard OS 2.0 model: layout/theme.liquid wraps a header group, the dynamic content_for_layout, and a footer group. Every page type is composed from JSON templates wiring sections together.

No React, no Vue, no headless. All interactivity is Vanilla JS using native Custom Elements (customElements.define). The theme editor is the primary merchant tool.

Architecture

Directory structure.

Directory Role Scale
sections/ Page modules with {% schema %} ~40 Liquid sections
blocks/ Nestable blocks (cs-*, FAQ, group) 14 files
snippets/ Reusable fragments 9 snippets
templates/ JSON composition by page type 14 templates
layout/ theme.liquid, password.liquid 2 files
config/ Global theme editor settings settings_schema.json
locales/ EN translations storefront + schema
assets/ CSS global, SVG, JS (e.g. QR gift card) 6 files

layout/theme.liquid is the single outermost shell. It renders a header-group (announcement bar + header), the page content via {{ content_for_layout }}, and a footer-group.

Each page type (product, collection, article, page, etc.) is defined by a JSON template that lists which sections appear and in what order. Merchants reorder them in the visual editor — no code required.

Styles are authored in plain CSS — no Sass, no PostCSS — using {% stylesheet %} blocks inside sections and a pair of global assets (critical.css, base.css). Zero build pipeline in production.

Features

What it includes.

Full Storefront Commerce

PDP with gallery, variants, qty selector, buy buttons, pickup availability, Shop Pay installments, and related products. PLP with faceted filters, quick view modal. Cart with notes, selling plans, discounts, and accelerated checkout.

Advanced Header System

Sticky nav with hide-on-scroll, mobile popover drawer, predictive search overlay, and a lateral AJAX cart sidebar — all wired to Shopify's Cart AJAX API and Section Rendering API with zero page reloads.

Dark Editorial Identity

Default dark palette (#0d0d0d / #dddbd7) with fully configurable primary and heading fonts via Shopify's font_picker. All tokens live in snippets/css-variables.liquid and cascade across the whole theme.

Content & Marketing

Blog with table-of-contents and reading progress, FAQ with tabs, oracle quiz, testimonials with world map, image hotspot, marquee, newsletter flyout, countdown hero, CTA with video, and custom Liquid section blocks.

Web Components Architecture

Every interactive region is a Custom Element registered via customElements.define. No framework overhead, no virtual DOM — just native browser APIs. Shared state lives on window.GrimoireCarousel, GrimoireProduct, and GrimoireQuickView.

CI-Ready Development

Develop locally with shopify theme dev (hot reload). Deploy with shopify theme push. GitHub Actions CI runs Theme Check on every push. MIT licensed — use for personal or commercial projects with no restrictions.
