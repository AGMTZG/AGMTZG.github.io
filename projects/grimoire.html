Overview

What is Grimoire?

Grimoire is a Shopify skeleton theme built to give developers a clean, opinionated starting point — not a blank canvas, not a bloated template. Every directory and file has a clear purpose, and the structure follows Shopify's official best practices.

The theme is organized around sections and blocks, giving merchants the flexibility to build custom page layouts from the Shopify editor without touching code.

Styling is done in plain CSS — no preprocessors, no build steps for styles — keeping the feedback loop fast during development. JavaScript is written in ES modules, loaded only when needed.

Grimoire supports full Shopify CLI integration for local theme previewing, hot-reloading, and deployment.

Features

What it includes.

Sections & Blocks

Full support for Shopify's section/block architecture. Merchants can build pages visually without touching code.

Liquid Templates

Cleanly separated layout, template, section, and snippet files. Easy to extend without breaking the structure.

Zero Build Step

No Webpack, no bundler. Plain CSS and ES module JavaScript — fast DX, no configuration overhead.

Responsive by Default

Mobile-first CSS that works across all screen sizes. No extra libraries or frameworks needed.

Shopify CLI Ready

Use shopify theme dev to preview locally with hot reload. Deploy with a single command.

MIT Licensed

Fully open source. Use it for personal or commercial projects, fork it, modify it — no restrictions.
