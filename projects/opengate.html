Overview

What is OpenGate?

OpenGate is a minimal API gateway designed for small-to-medium services that need a single entry point with authentication and rate limiting — without the complexity of a full-blown gateway like Kong or Nginx Plus.

Written in Go for performance. A single binary, no runtime dependencies. Routes are defined in a YAML config file and hot-reload without restart.

Rate limiting state is stored in Redis, so it works correctly across multiple gateway instances behind a load balancer.

A built-in dashboard shows real-time request counts, error rates, and latency percentiles (p50 / p95 / p99) per route — useful for spotting traffic spikes without spinning up a full observability stack.

Features

What it includes.

JWT Authentication

Validates JWT tokens on every request before forwarding to upstream services. Configurable public key or secret.

Rate Limiting

Token bucket algorithm backed by Redis. Per-route, per-IP, or per-user limits configurable in YAML.

Route Proxying

YAML-defined routing rules. Each route maps a path pattern to an upstream URL, with optional path rewriting.

Traffic Dashboard

Real-time request counts, error rates, and p50/p95/p99 latency per route. Updates every second via SSE.

YAML Config

All routes, limits, and auth settings in a single YAML file. Changes hot-reload without a gateway restart.

Single Binary

Compiles to a single Go binary with no runtime dependencies. Runs on Linux, macOS, and Windows.
