Overview

What is TaskFlow?

TaskFlow is a lightweight project management tool inspired by Kanban methodology. The focus was on building a real-time collaborative experience — when a teammate moves a card, everyone else sees it instantly without a refresh.

Boards, lists, and cards can be rearranged via drag-and-drop. Team members are shown as live presence avatars at the top of each board.

The backend is a Node.js/Express REST API with a Socket.io layer for real-time events. MongoDB stores boards, cards, and user data. Authentication uses JWT with refresh token rotation.

The React frontend uses optimistic updates — UI changes appear immediately while the server confirms in the background, keeping the experience snappy.

Features

What it includes.

Drag & Drop Boards

Rearrange cards across columns and reorder lists with smooth drag-and-drop built on the HTML5 Drag API.

Live Presence

See who's viewing each board in real time. Presence avatars update instantly as teammates join or leave.

Optimistic Updates

UI responds instantly to user actions. Server confirmations happen in the background — no perceived lag.

JWT Authentication

Secure login with JWT access tokens and refresh token rotation. Sessions persist across browser reloads.

Card Comments

Each card has a comment thread. Team members can leave notes, attach descriptions, and set due dates.

Activity Log

Every action on a board is logged — card moves, edits, comments — so you always know what happened and when.
