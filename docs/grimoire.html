Overview

Introduction.

Grimoire is a complete Shopify Online Store 2.0 storefront theme — dark, editorial, and production-ready. Built for lifestyle, fashion, and curated-object brands that need strong visual identity and storytelling alongside robust commerce.

The theme ships with ~40 sections, 14 blocks, 9 snippets, and 14 JSON templates covering every standard Shopify page type. All interactivity is written in Vanilla JS using native customElements.define — no framework, no build step.

Not a skeleton. Grimoire started from the official Shopify Skeleton but has grown far beyond it. It's a fully-featured theme ready for a real storefront — with its own design language, custom element library, and CI pipeline.

Design language

The default palette is built around near-black surfaces (#0d0d0d background, #111111 cards) with warm off-white text (#dddbd7). UI patterns throughout: uppercase eyebrows, hairline borders, luminous-border buttons, and --timing: 0.3s smooth transitions.

Typography is fully configurable via Shopify's font_picker. Two font pickers are exposed — primary (body/UI) and heading — and all variants are loaded via snippets/css-variables.liquid which outputs them as CSS custom properties.

Setup

Getting Started

Grimoire requires the Shopify CLI and access to a Shopify store (development or production). No Node, no bundler, no build step.

Prerequisites

Shopify CLI ≥ 3.x Required for local dev and theme push
Shopify store Development store recommended for testing
Git Clone the repository locally
GitHub Actions (optional) CI/CD pipeline with Theme Check

Installation

bash clone + dev 
# 1. Clone the repository
git clone https://github.com/AGMTZG/grimoire.git
cd grimoire

# 2. Authenticate Shopify CLI with your store
shopify auth login --store your-store.myshopify.com

# 3. Start local development server (hot reload)
shopify theme dev --store your-store.myshopify.com

# 4. Open the preview URL printed in the terminal
Tip: Use shopify theme dev --open to automatically open the preview in your browser when the server starts.

First-time setup in the theme editor

After starting shopify theme dev, open the theme editor and configure at minimum:

  • Typography — Set primary and heading font pickers under Theme settings → Typography
  • Colors — Adjust background, foreground, accent, and surface under Theme settings → Colors
  • Header — Select your navigation menu and configure transparent/opaque behavior
  • Slideshow — Add at least one slide to the homepage slideshow section
  • Footer — Set your logo, menus, newsletter, and social links
Internals

Architecture

Grimoire follows the standard Shopify OS 2.0 directory model. layout/theme.liquid is the single outermost shell that wraps every page.

Directory structure

grimoire/ layout/ # theme.liquid + password.liquid (2 files) sections/ # ~40 Liquid page modules, each with {% schema %} blocks/ # 14 nestable block files (cs-*, faq-item, group, text) snippets/ # 9 reusable Liquid fragments, documented via {% doc %} templates/ # 14 JSON templates — compose sections per page type config/ # settings_schema.json — all theme editor settings locales/ # en.default.json + en.default.schema.json assets/ # critical.css, base.css, SVG icons, JS (6 files)

Layout shell

layout/theme.liquid renders three top-level section groups in order:

layout/theme.liquid
{% render 'meta-tags' %}
{% render 'css-variables' %}

<body>
  {%- sections 'header-group' -%}
  {%- comment -%} renders: announcement-bar + header {%- endcomment -%}

  {{ content_for_layout }}
  {# resolved by templates/*.json → which sections fire #}

  {%- sections 'footer-group' -%}
  {%- comment -%} renders: footer {%- endcomment -%}
</body>

JSON templates

Each page type is defined by a JSON template in templates/. The file declares which sections appear and in what order — merchants can then reorder them in the theme editor without touching code.

templates/index.json (simplified)
{
  "sections": {
    "slideshow": { "type": "slideshow" },
    "trending":  { "type": "trending-products" },
    "marquee":   { "type": "marquee" }
  },
  "order": ["slideshow", "trending", "marquee"]
}

JavaScript model

All interactivity is Vanilla JS using native Custom Elements. Shared state is stored on window objects — no module bundler, no tree-shaking, no framework overhead.

window.GrimoireCarousel Swiper instance manager for slideshows and carousels
window.GrimoireProduct PDP state: selected variant, quantity, ATC lifecycle
window.GrimoireQuickView Quick view modal state and Section Rendering fetch
customElements.define() All interactive regions registered as Custom Elements
Reference

Snippets

Snippets are reusable Liquid fragments rendered via {% render 'name' %}. All snippets in Grimoire are documented with {% doc %} blocks — parameters are typed and described inline.

Shopify's snippet scope is isolated: variables defined outside are not accessible inside a rendered snippet unless passed explicitly as parameters.

css-variables.liquid

The theme's design-token hub. Loads all font variants from the Shopify CDN using font_face and outputs every CSS custom property consumed by the theme — colors, fonts, spacing, component-level tokens — inside a {% style %} block.

Rendered once, inside <head> via layout/theme.liquid. No parameters.

Key tokens output

CSS custom properties (subset)
/* Typography */
--font-primary--family:  {{ settings.type_primary_font.family }}, fallback;
--font-heading--family:  {{ settings.heading_font.family }}, fallback;

/* Layout */
--page-width:            {{ settings.max_page_width }};
--nav-height:            64px;
--header-total-height:   calc(var(--nav-height) + var(--announcement-bar-height));

/* Colors */
--color-background:      {{ settings.background_color | default: '#0d0d0d' }};
--color-foreground:      {{ settings.foreground_color | default: '#dddbd7' }};
--color-accent:          {{ settings.accent_color | default: '#dddbd7' }};
--color-surface:         {{ settings.surface_color | default: '#111111' }};

/* Timing */
--timing: 0.3s;

section-title.liquid

Renders an uppercase eyebrow with a hairline rule, followed by a large bold heading. Optionally renders a CTA link when btn_label is set. Used consistently across all major sections for visual coherence.

Parameters

ParamTypeDescription
eyebrowstringSmall uppercase label shown above the heading with a hairline rule
headingstringMain section title rendered as a large bold heading
heading_tagstringHTML tag for the heading element. Default: h2
btn_labelstringCTA button label. When blank, no button is rendered
btn_urlstringCTA href. Only used when btn_label is not blank
Usage
{# Basic usage #}
{% render 'section-title',
  eyebrow: 'The Ritual Paths',
  heading: 'Choose Your Intention'
%}

{# From section settings with CTA #}
{% render 'section-title',
  eyebrow:   section.settings.eyebrow,
  heading:   section.settings.heading,
  btn_label: section.settings.btn_label,
  btn_url:   section.settings.btn_url
%}

image.liquid

Renders a responsive image using Shopify's image_url and image_tag filters with automatic srcset generation. When url is provided the image is wrapped in an <a> tag; otherwise a <div>.

Parameters

ParamTypeDescription
imageimageThe Shopify image object to render
urlstringOptional destination URL — wraps image in <a>
classstringAdditional CSS class added to the wrapper element
widthnumberMax resolution width for image URL generation
heightnumberMax resolution height (used with crop)
cropstringCrop position: center, top, bottom, left, right
Usage
{# Simple image #}
{% render 'image', image: product.featured_image %}

{# Linked, fixed aspect ratio #}
{% render 'image',
  image:  product.featured_image,
  url:    product.url,
  class:  'product__image',
  width:  1200,
  height: 800,
  crop:   'center'
%}

product-card.liquid

The main product card component used across collection grids, carousels, search results, and quick view. Renders product image with hover overlay, title, price, compare-at price, color swatches, sale/sold-out badges, and an add-to-cart button.

All visual states (ATC hover, sold-out, sale badge) are controlled via CSS custom properties defined in css-variables.liquid under the --pc-* namespace. Styles are guard-loaded once with the product_card_styles_loaded assign trick.

Note: This snippet requires product-interactions.liquid to be rendered on the same page for add-to-cart functionality to work.

meta-tags.liquid

Outputs all head meta tags: charset, viewport, canonical URL, Open Graph tags (og:title, og:type, og:url, og:description, og:image), and Twitter card tags. Page type is auto-detected to set og:type to product, article, or website.

No parameters. Rendered once inside <head>.

Blocks

Blocks are nestable units that live inside sections. Grimoire ships with 14 blocks across three categories: custom section primitives (cs-*), content blocks (faq-item, text), and the layout container (group).

Blocks are declared in a section's {% schema %} under the "blocks" key. Merchants add, reorder, and configure them from the theme editor.

Custom Section Blocks — cs-*

The cs- prefix identifies Custom Section building blocks — composable primitives designed to be mixed inside custom-section.liquid and similar content sections. Each exposes its styling as theme-editor controls.

cs-heading.liquid Heading with configurable tag (h1–h6), font-size, weight, color, alignment, and vertical spacing
cs-subheading.liquid Smaller heading / subtitle, same controls as cs-heading at a reduced scale
cs-text.liquid Rich text paragraph block with color and alignment controls
cs-button.liquid CTA button with size (sm/md/lg), fill style, icon toggle, icon position, and row alignment
cs-image.liquid Image block with optional link, width constraint, and border-radius controls
cs-video.liquid Embedded video block supporting Shopify-hosted video or external embed URLs
cs-icon-item.liquid Icon + label row for feature lists. Icon rendered from Shopify's icon picker or custom SVG
cs-quote.liquid Pull quote / blockquote with attribution line and optional decorative quotation mark
cs-badge.liquid Small pill/badge text element with background color and text color controls
cs-divider.liquid Horizontal rule with configurable color, thickness, and vertical margin
cs-spacer.liquid Empty space block. Height in px, responsive override for mobile

Key sections explained

product.liquid — PDP

The product detail page section. Supports gallery, variant selector, quantity input, buy buttons (ATC + dynamic checkout), Shop Pay installments, pickup availability, JSON-LD structured data, 3D model viewer, color swatches, product benefits strip, and cross-sells via product-recommendations.liquid.

collection.liquid — PLP

Product listing page with faceted filters (Shopify's native filter API), configurable grid columns, sort controls, and quick view modal triggered by hover on product cards.

slideshow.liquid — Hero

Full-bleed homepage hero powered by Swiper 11. Each slide supports background image or video, headline, subtext, and a CTA. Autoplay, crossfade, and loop are configurable in the theme editor.

oracle-quiz.liquid

Interactive product quiz section. Merchants configure questions and answers in the theme editor; the section routes customers to a recommended product or collection based on their selections.

Development

CLI Commands

All Grimoire development and deployment is done through the Shopify CLI. No custom build scripts — the CLI handles hot reload, asset pushing, and deployment.

$ shopify theme dev --store your-store.myshopify.com
Starts a local development server with hot reload. Changes to Liquid, CSS, and JS files are reflected in the preview URL instantly. Opens on http://127.0.0.1:9292 by default.
$ shopify theme dev --open
Same as above but automatically opens the preview URL in your default browser on start.
$ shopify theme push --store your-store.myshopify.com
Pushes the local theme to your Shopify store. Use --publish flag to make it the live theme immediately. Prompts before overwriting if the theme already exists.
$ shopify theme push --unpublished
Uploads the theme as an unpublished draft — safe for staging and review without affecting the live store.
$ shopify theme check
Runs Shopify's Theme Check linter locally. The same check runs in CI via GitHub Actions on every push. Recommended before every theme push.
$ shopify theme list --store your-store.myshopify.com
Lists all themes on the store with their IDs. Useful for targeting a specific theme with --theme-id in push commands.
$ shopify theme pull --store your-store.myshopify.com
Downloads the live theme from your store to the local directory. Useful for syncing after merchant edits in the online theme editor.
GitHub Actions CI — The repository includes a CI pipeline that runs shopify theme check on every push and pull request. See .github/workflows/ for the configuration.

Useful flags

FlagDescription
--storestringYour store URL (your-store.myshopify.com)
--theme-idnumberTarget a specific theme by ID (from theme list)
--publishbooleanPublish the theme immediately after pushing
--unpublishedbooleanPush as an unpublished draft (staging-safe)
--openbooleanOpen the preview URL in a browser after starting dev
--nodeletebooleanPrevents deleting remote files not present locally during push
