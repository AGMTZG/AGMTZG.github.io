Overview

Introduction.

Grimoire (v1.0.0) is a commercial Shopify Online Store 2.0 theme by AGMTZG. It is a full storefront implementation, not a headless stack, not Hydrogen, built on Liquid, JSON templates, and the visual theme editor merchants already use.

The theme targets lifestyle, fashion, and curated-object brands that want a dark, editorial presence: strong typography, restrained grayscale surfaces, and room for storytelling sections alongside a complete commerce flow (browse, search, product detail, cart, and checkout handoff).

Commercial product. Grimoire is licensed for use on Shopify stores under your product terms. Documentation and support are provided for customers at agmtzg.github.io/grimoire/docs and agmtzg.github.io/support.

What you get

The codebase follows standard OS 2.0 architecture. layout/theme.liquid wraps every page with a header group (announcement bar + header), dynamic page content via {{ content_for_layout }}, and a footer group. Each page type is a JSON template that composes sections; merchants reorder and configure sections in the theme editor without editing code.

Out of the box the theme includes 40 sections, 14 blocks, 9 snippets, and 14 templates (including dedicated layouts for product, collection, cart, blog, article, search, password, gift card, and custom pages such as contact and about). Styles ship as plain CSS (assets/critical.css, assets/base.css, and co-located {% stylesheet %} blocks inside sections). There is no Webpack, Vite, or React runtime on the storefront.

Experience & commerce

Global navigation is handled by custom elements in sections/header.liquid: <site-navbar> (the default option is hide-on-scroll, but you can change it to sticky or static behavior), <search-overlay> for predictive search, and <cart-sidebar> for an AJAX cart drawer wired to Shopify’s Cart API. Product discovery spans homepage slideshows (Swiper 11), collection grids with filters, trending and recently viewed carousels, quick view modals, and related product recommendations.

The product detail section (product.liquid) supports variant selection, quantity, buy buttons, Shop Pay installments, pickup availability, media galleries, optional 3D models, and JSON-LD structured data. Shared client-side helpers: window.GrimoireProduct, window.GrimoireQuickView, and window.GrimoireCarousel, live in snippets and power cards, modals, and carousels across collection, search, and merchandising sections.

Design system

Grimoire’s visual identity is token-driven. snippets/css-variables.liquid maps theme settings into CSS custom properties for colors, typography, page width, header/cart/search surfaces, product cards, collection carousels, and more. Default colors are intentionally neutral and dark because the design follows a niche aesthetic commonly associated with mystical products, candles, and spiritual-themed brands, helping create a calm, atmospheric, and immersive visual identity. Those colors are:

  • Background — #0d0d0d
  • Surface — #111111 (cards, elevated UI)
  • Foreground / accent — #dddbd7 (warm off-white)
  • Inactive UI — #505050 (tabs, idle controls, eyebrows)

Typography uses two font_picker settings (primary and heading), with all weights loaded via font_face and exposed as --font-primary--* and --font-heading--*. Motion defaults to --timing: 0.3s. Editorial patterns, uppercase eyebrows, hairline dividers, and luminous primary buttons, are consistent across sections and the reusable section-title snippet.

Content & marketing sections

Beyond core commerce, Grimoire ships sections for brand storytelling and conversion: marquee, newsletter, signup flyout, FAQ with tabs, image hotspot, countdown hero, CTA with video, oracle quiz, testimonials (with world map), blog and news grids, and flexible page builders via custom-section.liquid plus composable cs-* blocks (headings, text, images, video, buttons, spacers, and more). Contact and about flows are covered by dedicated templates and matching sections.

Structure

Architecture

Everything in Grimoire is edited through the Shopify theme customizer. You do not need to open code files: you pick a page, adjust the sections on that page, and use Theme settings for store-wide typography, layout width, and colors. If you really need advanced customization, there is also a Custom Liquid section available for adding custom code, though this is intended for more advanced users.

Three places to customize

When you open Online Store → Themes → Customize, Grimoire organizes controls into three layers. Think of them top-down: global rules first, then the frame of every page, then the content of the page you are viewing.

1. Theme settings Typography, page width, margins, colors, favicon — applies to the entire store
2. Header & footer groups Announcement bar, navigation, search, cart drawer, and footer — visible on almost every page
3. Page template The stack of sections for Home, Product, Collection, Blog, Cart, and each Page

Theme settings (store-wide)

Open the customizer and click the gear icon or Theme settings in the left sidebar. Grimoire exposes three groups that control the look of the whole storefront:

GroupWhat you control
Typography Primary font (body and UI) and Heading font. Changes apply everywhere text is rendered.
Layout Page width (narrow or wide) and minimum page margin. Affects how much horizontal space your content uses on desktop.
Colors Background, foreground, accent, surface, input corner radius, and favicon. These feed the theme’s design tokens so header, cards, buttons, and product tiles stay consistent.

Additional store-wide controls are planned for future theme updates, for example button styles, card and product-tile treatments, motion preferences, and more header/footer defaults, so you can refine the look of Grimoire entirely from the theme editor without editing code.

Tip: Set colors and fonts in Theme settings before fine-tuning individual sections. Section-level options override layout details, but they inherit the global palette and type scale.

Header and footer (always on)

Grimoire uses Shopify section groups for the top and bottom of the store. In the customizer you will see them listed separately from the page you are editing:

  • Header group:Announcement bar (optional promo line) and Header (logo, main menu, search, account, cart). Header settings include scroll behavior (hide on scroll, sticky, or static), transparent header at the top of the page, logo image or text, main navigation menu, mobile drawer labels, search overlay copy, and cart drawer labels. Important: The header group is intended to contain only the announcement bar and the header itself, and it was not originally designed to support additional sections. However, I’m always open to merchants adapting the theme to fit their own needs and workflows.
  • Footer group:Footer with brand description, logo, social links, two navigation menus, newsletter signup, and payment icons. Important: Like the Header group, the Footer group was originally intended to support only the footer itself and was not designed for adding additional sections.

Changes here appear across the storefront. Assign menus under Content → Navigation in Shopify admin, then select those menus in the Header and Footer section settings.

Each type of page in your store has its own template. When you customize “Home”, “Default product”, “Default collection”, and so on, you are editing that template’s section stack, not a single global layout. Grimoire ships preset templates so you can start from a working layout and rearrange sections in the sidebar.

Sections: building a page

A section is a full-width module you can add, remove, reorder, and duplicate in the shopify theme editor. Examples include Slideshow, Collection grid, FAQ, Testimonials, and Custom section. Click Add section to browse Grimoire’s library; drag sections to change order; click a section to edit its settings in the right panel.

Many sections are self-contained (one settings panel). Others are built for specific page types, for example, the Product section only appears on product templates, and Cart only on the cart template.

Blocks: content inside a section

Some sections support blocks, smaller pieces you can add, reorder, or remove within that section. In the customizer, expand a section in the sidebar to see its blocks.

Common block patterns in Grimoire:

  • Product section: Title, description, price, variant picker, quantity, buy buttons, pickup availability, share buttons. Reorder blocks to change the order of information on the product page (for example, move description above price).
  • Product benefits: Individual benefit tiles (icon, title, text) in a row below the product.
  • Breadcrumb: Home link, collection crumb, and current page. Toggle labels and separator style in section settings.
  • FAQ: One block per question/answer pair, grouped by category tabs you configure in section settings.
  • Contact channels: One block per support/sales card.
  • Chronicle (About): One block per story chapter (eyebrow, heading, body, image side).
  • Custom section: See below; this is the theme’s flexible page builder.

Custom section (page builder)

Custom section is the most flexible layout tool in Grimoire. Add it to any page template to build editorial layouts from blocks without code. Section settings let you control section title (eyebrow + heading), alignment, max width (narrow, default, or full bleed), spacing, optional background image with overlay, and gap between blocks.

Available blocks inside Custom section:

Heading Subheading Text Image Video Button Badge Quote Icon item Divider Spacer Group

Use Group when you need a nested row or column of blocks. You can stack up to 16 blocks per Custom section instance, duplicate the section on the page if you need more.

Special-purpose sections

Custom Liquid A single text area for Liquid or HTML snippets (app widgets, embeds). Use only if you are comfortable with code or following an app’s install instructions.
Page Renders Shopify page content from the admin. Optional table of contents and reading progress bar for long editorial pages.
Signup flyout Global-style newsletter popup; configure timing and copy in section settings (add to templates where you want it to appear).
Oracle quiz Interactive quiz that routes shoppers to a product or collection based on answers, configured entirely in the section and its blocks.

Recommended workflow

  1. Configure Theme settings (fonts, colors, page width).
  2. Set up Header and Footer (logo, menus, newsletter, social links).
  3. Customize the Home template: slideshow, collections, trending products, then add storytelling sections as needed.
  4. Review Product and Collection templates, adjust product blocks, filters, and merchandising sections.
  5. Build Pages (About, Contact) using Page + Custom section + dedicated contact/chronicle sections.
  6. Create additional page templates in Shopify admin if you need alternate layouts (for example, a landing page without the default breadcrumb).
Presets are starting points. Duplicating a template in Shopify admin (Theme → … → Duplicate) lets you keep Grimoire’s defaults for one use case while building a second layout (e.g. a minimal landing page vs. a full homepage) without affecting the rest of your store.
Reference

Snippets

Snippets are reusable Liquid fragments rendered via {% render 'name' %}. All snippets in Grimoire are documented with {% doc %} blocks — parameters are typed and described inline.

Shopify's snippet scope is isolated: variables defined outside are not accessible inside a rendered snippet unless passed explicitly as parameters.

css-variables.liquid

This snippet is Grimoire’s global style sheet in one file. It is not a section you add in the customizer, it runs on every storefront page and outputs a single {% style %} block of CSS custom properties (--token-name) that the rest of the theme reads. Sections and snippets reference those variables instead of hard-coding colors or font stacks, so a change in Theme settings can ripple across headers, cards, carousels, and forms in one place.

It is included in the document <head> from the main layout (and the password and gift card layouts). It accepts no render parameters, only Shopify settings.* values and fixed defaults defined in the snippet itself.

What you control vs. what is preset

Think of the tokens in two buckets. Merchant-linked properties are rebuilt from your Theme settings whenever the theme loads. Component presets are tuned rgba values and shadows for specific UI (cart drawer scrim, product-card hover border, carousel arrows) that stay consistent with Grimoire’s dark editorial look even when you recolor the store.

Font loading

Before the :root block, the snippet registers primary and heading font files from Shopify’s CDN (regular, bold, italic combinations) with font-display: swap. Picking fonts in Theme settings is enough (We use the font Merryweather as the default font family), you do not upload font files separately. Every section that uses var(--font-primary--family) or var(--font-heading--family) picks up the same faces.

Token namespaces (where they show up)

Variables are grouped by comment blocks in the snippet. The prefix tells you which part of the storefront consumes them:

PrefixStorefront areas
--font-*, --page-* Body copy, headings, max content width, horizontal padding on page shells and Custom section inner containers.
--nav-*, --header-* Site navbar height, announcement offset, mobile drawer, search overlay, cart sidebar (surfaces, text tiers, scrims, quantity controls, checkout hover).
--color-*, --primary-button-*, --is-*-color, --eyebrow-line-color Page background, text, cards, eyebrows and dividers, primary CTA buttons, inactive controls (tabs, icons).
--coll-* Homepage Collections carousel: arrow buttons, collection cards (border, title, description, “Explore” link), empty image placeholder.
--tp-* Trending products category tabs and carousel arrows (inactive tab color vs. active accent).
--pc-* product-card snippet everywhere grids appear: media frame, hover border, image overlay, sale/sold-out badges, title and prices, add-to-cart states, color swatches.

Practical tips for merchants

  • If a section looks “almost right” after a rebrand, start with accent and surface in Theme settings, many highlights and card backgrounds reference those tokens indirectly.
  • Section-specific colors (slideshow overlay, FAQ tab labels, a single banner background) are controlled in that section’s settings, not in this snippet.
  • You can use Shopify’s built-in Custom CSS feature to easily add your own styles and personalize the theme without modifying the theme files directly.
Spacing under a fixed header: Sections that pin content below the navigation (for example FAQ filters) use var(--header-total-height) or var(--nav-height) so content does not sit underneath the bar when the announcement bar or a taller logo is present.

section-title.liquid

Shared section header for Grimoire: a short label (eyebrow), a large title, and an optional text link styled as a button. You will not add this snippet manually in the theme editor, sections that support it expose Eyebrow, Heading, and sometimes Button label / Button link fields in their own settings panel. Leaving a field empty hides that part of the header (for example, heading-only or eyebrow-only is valid).

What you see on the storefront

  • Eyebrow: Small caps line with horizontal rules on either side (mobile: centered with rules; desktop: left-aligned, rule extends to the right).
  • Heading: Large display title using your Theme settings heading font; scales with viewport width.
  • Optional CTA: Uppercase outline button with a chevron icon, shown only when a button label is set. If a link is missing, the button falls back to #, always set Button link when you add a label.

On viewports 768px and wider, the heading and CTA sit on one row (title left, button right). Below that breakpoint, both stack and center for easier reading on phones.

image.liquid

A small developer utility for outputting a Shopify image with responsive URLs. It is not something you add from the theme customizer, merchants add pictures through each section’s image picker fields, or through the Image block inside Custom section (that block uses its own markup in blocks/cs-image.liquid, not this snippet).

Grimoire keeps image.liquid as a documented pattern for theme extensions: pass a Shopify image object, optionally cap resolution, crop to an aspect ratio, or wrap the graphic in a link.

Where merchants add images instead

ContextHow to add or change images
Custom section Add an Image block: width, alt text, border radius, and alignment are in the block settings.
Slideshow, Collections, Chronicle, etc. Use that section’s own image or background fields in the customizer.
Product & collection pages Product media and collection images come from the Shopify admin catalog, not from this snippet.
Header & footer Logo image picker in the Header section; footer logo in Footer settings.

What the snippet outputs

  • Wrapper: A <div class="image"> by default, or <a class="image"> when url is set so the whole image is clickable.
  • Picture: Built with Shopify’s image_url + image_tag filters (responsive srcset is handled by image_tag).
  • Aspect ratio: When both width and height are passed (with optional crop), Shopify crops to that box. If height is omitted, width defaults to the source image’s native width.
  • Layout CSS: A co-located stylesheet makes the wrapper full width and the <img> scale with height: auto.
Alt text: This snippet does not accept a separate alt parameter, it relies on the alt stored on the image in Shopify admin. For editorial blocks, use the Image block in Custom section, which includes a dedicated Alt text field.

imageimageRequired. The Shopify image object (from a product, collection, setting, or block).

classstringExtra class on the wrapper (e.g. for section-specific CSS).

product-card.liquid

The reusable product tile in Grimoire: image, sale/sold-out badges, title, price (and compare-at when on sale), optional color swatches, and an action button. Sections render it inside grids or carousels, you do not add the snippet from the theme customizer. What you control as a merchant is which products appear in each section (collections, recommendations, search results) and your catalog data (images, variants, pricing).

What shoppers see on each card

  • Media: Square image with a subtle gradient overlay; image zooms on hover (behavior depends on hover mode below).
  • Badges: “Sale” when the product is discounted; “Sold out” when the selected color has no available inventory.
  • Swatches: Shown only when the product has a Color or Colour option in Shopify admin. Clicking a swatch updates the preview image, active variant, and sold-out state on that card.
  • Title & price: Linked to the product page. Compare-at price appears struck through when on sale.
  • Action button: Either adds one unit to the cart via AJAX (cart drawer opens) or opens the quick view modal first, see the next section.

Add to cart: two behaviors

product-interactions.liquid

Loads the shared window.GrimoireProduct script once per page. It powers color swatches on product cards and routes Add to cart clicks on cards configured to open quick view instead of adding immediately.

You do not add this snippet yourself in the theme editor. It is included automatically when a section renders product-modal.liquid. Merchants only see the outcome: tapping a swatch updates the card image and variant; tapping ATC on a quick-view card opens the modal.

What it does on the storefront

  • Swatch clicks: Updates the active swatch, color label, variant id on the ATC button, sold-out badge, and product image (with a short crossfade).
  • ATC with quick view: When the card button has data-opens-modal, opens the quick view modal populated from that card’s data instead of navigating away.
  • Fallback: If no modal is present, ATC falls back to the product URL on the card.

Sections that rely on it

Any section that calls GrimoireProduct.bindCards(...) after rendering cards and a modal: Trending products, Product recommendations, Recently viewed, Collection, and Search.

product-modal.liquid

The quick view dialog: a full-screen overlay with product image, title, price, color swatches, quantity, Add to cart, Buy now, and a link to the full product page. One modal shell is rendered per section that needs it (for example Trending products or Collection).

Quick view is enabled per product card in sections that support it (for example Trending products cards inside category blocks). In the theme editor, look for settings on the section or block that control quick view / modal behavior, you do not edit product-modal.liquid directly.

Label copy inside the modal (Add to cart, Buy now, View full details, Sale, Sold out, Quantity) can be overridden by passing optional parameters when the section renders the snippet (defaults are Grimoire-themed strings such as “Add to Grimoire”).
